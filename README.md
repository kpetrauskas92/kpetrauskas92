# Hi, I'm Karolis 👋

**IT Support • Cybersecurity & GRC • Full-Stack Developer**
📍 Limerick, Ireland

I work in IT support and escalation at Tierney's Office Automation, and I'm moving into cybersecurity with a focus on **Governance, Risk and Compliance (GRC)**. I have a background in web development (Python, Django, JavaScript, WordPress), and I like building practical tools that make security easier to understand.

- Preparing for **CompTIA Security+**
